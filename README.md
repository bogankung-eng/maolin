# 毛邻

> 毛孩子邻里社区 — 宠物社交 + 健康管理

---

## 技术栈

| 类别 | 选型 |
|---|---|
| 框架 | Vite + React 18 |
| 路由 | React Router v6 |
| 状态 | Zustand |
| 样式 | Tailwind CSS 3 + TypeScript |
| 测试 | Vitest + Testing Library — 34 条全绿 ✅ |
| 工具 | Prettier + ESLint 9 (flat config) |

## 功能

| 模块 | 说明 |
|---|---|
| 信息流 | 宠物动态 Feed + 分类筛选 |
| 问答 | 社区问答（Q&A） |
| 发布 | 图文发布 |
| 个人 | 宠物档案 + 健康记录 |
| 详情 | 帖子详情页 |

## 本地开发

```bash
npm install
npm run dev        # → Vite 开发服务器
npm run test       # Vitest 单测
npm run lint       # ESLint
npm run format     # Prettier 格式化
npm run build      # tsc + vite build
```
